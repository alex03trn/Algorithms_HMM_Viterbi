# Algorithms_HMM_Viterbi
Данный репозиторий содержит в себе:

файл hw1_HMM_Viterbi.py, где описано решение HW1 с определенными последовательностями определенных бактерий (см. отчет). Также прикладываются два fasta файла с последовательностями хромосом, с которыми была сделана работа.

Файл viterbi.py для локального запуска в командной строке с использованием произвольных последовательностей. 

Программа использует скрытую марковскую модель (HMM) с алгоритмом Витерби для сегментации ДНК последовательностей по GC-составу. Два референсных генома обучают эмиссионные вероятности, тестовая последовательность декодируется на скрытые состояния (1 или 2).

## Требования
- Python 3.6+
- `pip3 install numpy biopython`

## Скачать программу:
```
wget https://github.com/alex03trn/Algorithms_HMM_Viterbi/raw/main/viterbi.py
```

ref1.fasta   геном с низким GC - состояние 1    
ref2.fasta   геном с высоким GC - состояние 2  
test.fasta   ваша тестовая последовательность

## Использование
python3 viterbi.py ref1.fasta ref2.fasta test.fasta
